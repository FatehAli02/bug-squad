## 1. Root Cause Summary
to_csv_rows in utils.py was declared with headers: List[str] = []. Python evaluates default argument expressions exactly once at function-definition time, so every call that omits headers shares the same list object. Any code that obtained a reference to that shared default and mutated it (via extend, append, or +=) would corrupt all subsequent headerless calls, which would then receive the already-mutated list instead of the canonical six-column default. The fix is to use headers: Optional[List[str]] = None and guard internally with `row_headers = headers if headers is not None else default_headers`.
