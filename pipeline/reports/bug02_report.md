## 1. Root Cause Summary
ExpenseTracker.update_expense (api.py line 87-88) calls self.get_expense(expense_id), which returns None when the ID is not found. The very next line dereferences exp.title (if exp.title is None:) without first checking whether exp itself is None. This raises AttributeError: 'NoneType' object has no attribute 'title' instead of the intended ValueError('Expense ... not found.'). The fix is to guard with `if exp is None:` before touching any attribute of exp.
