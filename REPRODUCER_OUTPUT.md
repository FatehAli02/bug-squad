**Failure output:**
```

  assert Derived(schema).is_valid(9)
```
**Summary:** In JSON Schema Draft 4, sibling keywords alongside a `$ref` are
ignored — only the `$ref` target is evaluated. `Draft4Validator` therefore

resolution so that the derived class enforces sibling keywords, causing
`Derived(schema).is_valid(9)` to return `False`. The test asserts that an
empty extension validates identically to the base class.
